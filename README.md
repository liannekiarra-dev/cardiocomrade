
Title: Cardio Comrade
Type: Fitness Tracker

Functionality: Running tracker, health, fitness inspiration, physical activity tracker

Running tracker
- This allows the user to use a built in timer 
- functionality calculates for a route, its distance and estimated time it takes to complete 

Health:
- BMI tracker for several months
- Calorie Counter for daily and tracking calorie intake for a period of time

To run:
- go to cardio_comrade folder nad open it in vscode
- provide emulator preferably iphone 17 iOS
- terminal command 'flutter run'
